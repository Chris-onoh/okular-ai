## Upstream Okular

This project is a fork of [KDE Okular](https://invent.kde.org/graphics/okular),
developed by the KDE community. The document engine, generators, annotations,
forms, printing and most of the application code are upstream work.

The user-visible About dialog lists the principal upstream authors, including:

- Pino Toscano — former maintainer
- Tobias Koenig — framework work, FictionBook backend and former ODT backend
- Albert Astals Cid — developer
- Piotr Szymanski — created Okular from the KPDF codebase
- Enrico Ros — KPDF developer

Additional credits include Eugene Trounev (annotations artwork), Jiri Baum /
NICTA (table selection tool) and Fabio D'Urso (annotation improvements).

The full upstream history and contributor list are available in the Git history
and in the copyright headers of individual source files.
